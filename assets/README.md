# Brand assets

Official Clearbox brand assets for this repo. Sourced from the canonical Clearbox asset store — never redrawn, never recolored.

| File | Use |
|---|---|
| `logo-dark.png` | Full wordmark for dark backgrounds |
| `logo-light.png` | Full wordmark for light backgrounds |
| `banner.png` | README header (1280×360) |
| `social-preview.png` | GitHub social preview (1280×640) — upload in repo Settings |

## Rules

- These are the only approved renderings. Don't stretch, restyle, or re-derive them.
- The banner and social preview are generated compositions built from the official logo on the brand dark background (`#0d0d12`) with the brand accent (`#6d5ee9`).
- Need another size or variant? Open an issue rather than editing these files.
