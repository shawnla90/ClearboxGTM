# Stories

The qualitative complement to `proof-data.json`.

Every claim in these stories traces to a database query run by `proof/generate_proof.py` or to a public artifact anyone can verify. No client names, no identifying details, no hand-typed statistics.

The numbers come from `proof-data.json`, which is regenerated on every release from the tracking databases opened read-only. If a number here does not match what is in `proof-data.json`, the number here is wrong.

## What is here

- [**No backlinks needed**](no-backlinks-needed.md) — the thesis that AI citations come from being helpful, not from SEO link-building
- [**Inbound from content**](inbound-from-content.md) — the pattern where genuine replies attract genuine responses, and how that compounds into pipeline
- [**LinkedIn outbound**](linkedin-outbound.md) — the Clearbox playbook as a LinkedIn outbound message, with the exact messages and 16-day funnel

## Rules for adding a story

1. Every number must come from `proof-data.json` or a query in `generate_proof.py`
2. No client names, company names, or details that identify a specific deal
3. No screenshots of private conversations or DMs
4. Reference public artifacts (Reddit threads, podcast episodes, repo commits) by permalink when possible
5. Label anything generated or estimated — the same rule the engine follows
