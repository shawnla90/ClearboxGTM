# Transparency

What actually built the Clearbox user base — including what failed. Growth content usually shows the winning channel and buries the rest; this folder publishes the whole ledger, because the failures shaped the method as much as the wins did.

- [`what-actually-worked.md`](what-actually-worked.md) — the honest channel ranking, with the attribution caveats stated instead of hidden.
- [`cold-email-postmortem.md`](cold-email-postmortem.md) — we built a full cold-email stack and it mostly didn't work. What the data showed, what it cost, and the deliverability lessons worth keeping.

The rules of this folder are the rules of the repo (see [`../VERIFYING.md`](../VERIFYING.md)): every number is generated by [`../proof/generate_proof.py`](../proof/generate_proof.py) or shown next to the query that produced it, and claims that can't be sourced get cut.
