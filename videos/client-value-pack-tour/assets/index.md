# Frozen showcase assets

Every asset is a verified screenshot of the public, sanitized Acme Ops demonstration pack. No image contains a real client, private operator URL, account token, email address, or private processing workspace.

| Asset | Source surface | Use |
|---|---|---|
| `dashboard.png` | Public view-only Google Sheet | Branded dashboard and eleven visible working tabs |
| `plan-setup.png` | Public view-only Google Sheet | Offer path, payer, and readiness selections |
| `operator-console.png` | Public view-only Google Sheet | Ranked queue with Clearbox disposition and review state |
| `geo-terms.png` | Public view-only Google Sheet | Exact Reddit source URLs and separate evidence fields |
| `notion.png` | Public Notion demo | Recommendation, Sheet link, value summary, and guided next steps |

The images are copied from `assets/gallery/` so the HyperFrames project remains deterministic and self-contained. The composition may crop, pan, zoom, frame, or spotlight these screenshots. It may not redraw the UI or invent completed evidence fields.
